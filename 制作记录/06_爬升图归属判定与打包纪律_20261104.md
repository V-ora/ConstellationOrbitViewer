## 一、两次同类 bug 的复盘

| 图 | 现象 | 根因 |
|---|---|---|
| 千帆 | 悬停「极轨19组」时，805 km 那一组也被加粗 | 高亮按**发射日**匹配；极轨19组（2026-09-15 06:26 UTC）与极轨26组（2026-09-15 22:00 UTC）在同一 UTC 日 ⇒ 多算 9 颗 |

## 三、打包纪律（这次踩的坑，必须记住）

**改过 `web/` 或 `data/` 之后，重打 exe 必须 `--clean`。**

原因：PyInstaller 增量打包会复用上一次的资源副本，`web/raise/*.html` 改了但 exe 里还是旧的。
本次现象：exe 内置页面 `hoverCos=0`（旧版），而工程目录里的文件是对的；换 `--clean` + 全新 workpath 后立刻正确。

正确姿势：

```bat
set COV_RUNTIME_HOOK=_ct_data_src_hook.py
set COV_EXE_NAME=星座轨道实时查看器_CelesTrak版
python -m PyInstaller --clean --noconfirm --workpath build\x1 --distpath dist_x spec_onefile.spec
```

验证方法：起 exe 后请求 `/web/raise/千帆星座轨道爬升交互大图.html`，确认含 `global.ChartCore`。
