## 航天词条图片核查 · 卫星百科文件页「引用格式」规范（用户追问）
- **用户问**："卫星百科引用的格式是什么"（起因：QQ 群中有人上传 文件:海星辐射.png，摘要只写"来源：https://en.wikipedia.org/wiki/STARAD"，被群主指出"引用的格式不对"）。
- **查证方法**：用 MediaWiki API 直接读**文件页 wikitext 源码**（`prop=revisions&rvprop=content`）+ 读系统消息 `MediaWiki:Licenses`。关键：**不要只看渲染页**，渲染页看不出模板名与结构。
- **结论（站内实测，无 {{Information}}/{{文件信息}} 模板）**：固定两段式 ——
  ```
  == 摘要 ==
  <图片内容说明>
  来源：<原始出处链接>

  == 许可协议 ==
  {{许可模板}}
  ```
- **官方许可模板（10 个，来自 MediaWiki:Licenses）**：`{{No license}}`(不知版权)、`{{Self}}`(自制/自摄)、`{{Prtsc}}`(出版物截取)、`{{Web}}`(航天机构/企业等官方渠道)、`{{From Wikimedia}}`(来自维基媒体基金会)、`{{CC-BY-SA}}`、`{{Other free}}`、`{{PD}}`(公共图片)、`{{Fairuse}}`(合理使用)、`{{Permission}}`(版权方已授权)。注意：**这些模板在站内目前都是红链**（未从灰机模板仓库导入），但仍属站方规定写法。
- **实测样例**：文件:RL10A4.jpg / RD-171.jpg 用 `{{From Wikimedia}}`；文件:Tianyi41.jpg / Donaldjohanson.png → `{{Web}}`；文件:HEMPT.png → `{{Prtsc}}`；文件:8104Sat Camera.jpeg → `{{Self}}`。反例：文件:海星辐射.png 与 文件:SJ 26.png(Maxar) 都**缺 `== 许可协议 ==` 段**。
- **交付**：新增参考文档 `D:\Work Buddy 工作区\航天词条图片核查\卫星百科文件页格式.md`（含规范、模板清单、实测源码、三张图的建议写法）。
- **经验**：卫星百科文件命名另有《Project:文件命名准则》（须含对象名、禁用无意义数字字母）；上传权限仅限 管理员/认证用户/机长/职员/全局管理员（`Special:Upload` 对普通用户报权限错误）。

### 修正：start.bat 双击没反应（已修复并实测通过）

- **现象**：用户双击 `星座轨道实时查看器\start.bat` 后浏览器不弹、服务也没起。
- **根因（两个）**：
  ① 该 .bat 是 **LF-only 换行**（Write 工具默认行为），cmd.exe 解析错乱 —— `rem` 行里的词被当成命令执行
     （`'Constellation' / 'NOTE:' / 'the' 不是内部或外部命令`），脚本半路崩在 `pause`；
  ② 文件里残留**非 ASCII 内容**（注释里写了「说明.md」），cmd 用 OEM 代码页解码 → 整行变乱码命令。
- **修复**：重写 start.bat 为**纯 ASCII + CRLF**，并用 `t.encode('ascii')` 自检通过（注释里连中文文件名都不出现）；
  同时加固 `server.py` 的打开逻辑：`webbrowser.open(new=2)` → `os.startfile` → `subprocess cmd start` 三级兜底，
  用 `subprocess "clip"`（utf-16-le）把地址写进剪贴板，并打印 `=====` 横幅把 URL 单独一行印出来；
  开浏览器前先 `probe_tcp` 轮询确认端口在 accept，再 sleep 0.35s，避免刚打开就连接被拒。
- **实测**：批处理输出干净无一处报错，中文正常显示，8770 监听成功、`/api/ping` 返回 200，
  日志依次出现「地址已复制到剪贴板」「已尝试用默认浏览器打开页面」。
- **经验已落地**：写进技能 `celestrak-orbit-viewer` 的「start.bat 两条死规矩」，
  并写进用户级 `~/.workbuddy/MEMORY.md`（.bat 必须 CRLF + 纯 ASCII；COM 建桌面快捷方式会被安全策略拦）。
