## 一、项目是什么

`D:\Work Buddy 工作区\星座轨道实时查看器\` —— 一个 Windows 单文件 exe + 本地 Web 程序：
**实时查看千帆（QIANFAN）与国网/星网（HULIANWANG DIGUI）星座的轨道运行情况**。

- 双击 `星座轨道实时查看器.exe` 即用（无需 Python），服务起在 **http://127.0.0.1:8770/**（占用自动换端口）；
  源码版双击 `start.bat`。
- 四个视图：**3D 地球**（WebGL，真实纹理+昼夜晨昏线+轨道圈）/ **2D 地面轨迹**（等经纬+覆盖圆+夜阴影）/
  **轨道爬升图**（iframe 内嵌千帆、星网两张大图 + 组次叠加图 batch.html + 单星图 sat.html）/
  **过境预报**（2026-10-07 新增：填观测点 → 「此刻头顶」+「未来过境」列表，纯前端几何过境）。
- 界面要点：顶部页签切视图；星座卡片「组次 ▸」开组次面板，选组后左栏显示组次资料、
  状态条「🔭 正在查看：…（N 颗）[退出组次]」；点卫星出详情面板（含「取消选中」，2026-10-06 前叫「退出查看」）；
  轨迹/覆盖圆开关只在选中星或聚焦组次时出现（回全部视图自动隐藏并复位）；
  覆盖圆按**可调最低仰角**算（`≥10°` 档位下拉框就在「覆盖圆」按钮右边，5/10/15/20/30°，
  默认 10°，**与过境预报的最低高度角共用同一个取值、两处互相同步**）；
  爬升图视图下「跟随选中/适配视野」按钮排整排隐藏（main.vraise #vlabel{display:none}）。

  联网失败 5 分钟冷却秒回缓存（绝不复活死代理、绝不每次重撞超时）。
- 缓存：源码版 `cache\`；exe 版 `%LOCALAPPDATA%\ConstellationOrbitViewer\cache`。

## 四、必须遵守的约定（铁律）

1. **CelesTrak 一天只做一轮完整抓取**；验证一律用缓存/离线手段，绝不在同一 IP 连续多轮打请求
   （封禁三档：403 约 1h → 丢包档约 78min 自动解封；records.php 与 gp.php 限流独立）。
2. 改完 UI **必须 CDP 真实输入自检**（`_selfcheck.mjs`，36 项）：Emulation.setDeviceMetricsOverride
   设视口（1600×900，太矮会把 #list 挤成 0 高产生假阴性）+ Input.dispatchMouseEvent 真实鼠标；
   合成事件/静态 grep 不算数。**改动的功能若已有专项脚本（`_chk_pass.mjs` / `_chk_cover.mjs`）要一并跑**，
   更要对**打包好的 exe** 再跑一次专项脚本（脚本都支持传 URL）。
   ★ 每个 `_chk_*.mjs` 占一个固定 CDP 端口，**连续跑要间隔几秒**，否则 `FATAL: CDP target 未就绪`；
   偶发**单次** FAIL 先复跑，别急着当 bug。
3. exe 更新全流程替用户做完：PyInstaller 打包 → `taskkill /IM 星座轨道实时查看器.exe /F`
   （onefile 双进程全杀）→ cp 到项目根 + `不含过境预报版\`（**`交付物\04` 自 10-09 起只留 README，不再放 exe**）
   → **两侧 MD5 核对** → run_in_background 启动 → `curl /api/ping` 验证 boot。⚠️ 命令内 `... & sleep` 起 exe 会被 shell 带走，必须 run_in_background。
   ★ **打包前先把 dist\ 里要覆盖的旧 exe `mv` 走**（别用删除）：本机安全策略会拦下 PyInstaller 的覆盖删除
   （`OSError: SHFileOperationW 失败: 0x2`），结果是旧 exe 被删、新 exe 没生成。四个 exe 各用一个
   `--workpath`（wp_main / wp_main_d / wp_nopass / wp_nopass_d），避免两套变体的 Analysis 缓存互相污染。
4. 交付物约定：成品进 `D:\Work Buddy 工作区\交付物\`；CSV 一律 utf-8-sig；
   移动/删除前先备份 zip 到 `.整理备份\`。脚本/原始数据/缓存留在原地不动。
5. `.bat` 必须 CRLF + 纯 ASCII；本机删文件不进回收站（先 zip 备份再 os.remove）。
6. 只读核查站点时从不改动卫星百科；其 API **直连间歇性 403（Cloudflare）**，对我首选 WebFetch，
   写进程序要**独立枚举出口候选**（本机监听端口用 `netstat` 现扫，别硬编码端口）。
