### 1. 重新生成两张爬升大图并上线（**推荐直接用这条**）

```bash
cd "D:\Work Buddy 工作区\星座轨道实时查看器"
"C:\Users\t2007\.workbuddy\binaries\python\envs\default\Scripts\python.exe" refresh_deliverables.py
```
它会依次（**六步**）：追平逐日历史 → 千帆大图 → 国网大图 → **同步到 `web_live\raise\`（大图覆盖层）** → 生成 `web_nopass\` 无过境变体 → 用无头 Edge 截两张 PNG（**并行**，各用 `SHOT_DBG=9341/9342`）。日志写 `refresh.log`。
加 `--no-png` 跳过截图更快。也可以直接双击 `refresh_deliverables.bat`。

> **耗时基线（2026-10-19 实测 12.1 s，优化前 27.6 s）**：
> ①追平历史 4.5 s ②千帆图 1.0 ③国网图 1.1 ④同步 `web_live` 0.2 ⑤无过境变体 2.3 ⑥两张并行截图 1.8。
> 提速点：截图从「盲等 4 s + 0.9 s」改成**条件等待**（`readyState` → canvas 非空像素数连续 5 次采样不变
> → 文档高度连续两次相同，超时只 `WARN` 不强退），单张 5.8 s → 1.4 s；`local_backfill.py` 改成
> **直连优先 + 记住成功出口**并把高轨与两个组接口并发，11.9 s → 3.4 s（网络差时原来能跑出 82 s）。
> ★ 判断「canvas 画完」不能只用「非空像素 > 0」—— 画布先画背景/网格就已经 > 0（实测 221000），
> 画完是 1161615，必须等像素数**稳定**。

> 只想要其中一张：`python make_qf_html.py`（千帆）/ `python make_gw_html.py`（国网低轨）。
> 两者都会把产物**同时写回** `web\raise\` 和 `交付物\01_卫星轨道核查\`，**不需要再手动 cp**（旧手册里的

### 2. 重打包 exe + 替换 + 核对（全流程）

```bash
cd "D:\Work Buddy 工作区\星座轨道实时查看器"
PY="C:\Users\t2007\.workbuddy\binaries\python\envs\default\Scripts\python.exe"

# ★ 打包前：先把 dist\ 里要覆盖的旧 exe **挪走**（mv，不要用删除/rm）
mkdir -p ".整理备份/dist_prev_$(date +%Y%m%d)"
mv dist/*.exe ".整理备份/dist_prev_$(date +%Y%m%d)/"

# 含过境预报的两版（各自独立 workpath，避免 Analysis 缓存互相污染）
"$PY" -m PyInstaller --noconfirm --workpath build/wp_main   spec_onefile.spec    # 浏览器版
"$PY" -m PyInstaller --noconfirm --workpath build/wp_main_d spec_desktop.spec    # 桌面版

# 变体：不含「过境预报」（先跑 _make_nopass.py 生成 web_nopass\，再改两个环境变量）
"$PY" _make_nopass.py            # 若提示「变体页指纹变了」且确认是有意改动：NO_PASS_ACCEPT=1 "$PY" _make_nopass.py

COV_EXE_NAME=星座轨道实时查看器_SpaceTrack版_桌面版 COV_RUNTIME_HOOK=_st_data_src_hook.py "$PY" -m PyInstaller --noconfirm --workpath build_st_desktop spec_desktop.spec

# 分发（**只两个去处**：工程根 4 个 + 不含过境预报版\ 2 个；交付物\04 只留 README）
cp -f dist/星座轨道实时查看器.exe                   ./星座轨道实时查看器.exe
cp -f dist/星座轨道实时查看器_桌面版.exe             ./星座轨道实时查看器_桌面版.exe
cp -f dist/星座轨道实时查看器_SpaceTrack版.exe       ./星座轨道实时查看器_SpaceTrack版.exe
cp -f dist/星座轨道实时查看器_SpaceTrack版_桌面版.exe ./星座轨道实时查看器_SpaceTrack版_桌面版.exe
cp -f dist/星座轨道实时查看器_无过境预报.exe        "./不含过境预报版/星座轨道实时查看器_无过境预报.exe"

# 六对 MD5 必须两两相同
md5sum dist/*.exe *.exe "不含过境预报版/"*.exe
"$PY" _verify_exe_payload.py          # 再拆包核对六份 exe 的变体归属 / 数据源归属 / 内嵌数据（52 项）
```
★ 打包前先备份旧 exe 到 `.整理备份\dist_prev_<日期>\`。
★ **覆盖 dist 里已有同名 exe 时，本机安全策略会拦下 PyInstaller 的删除动作**（`OSError: SHFileOperationW 失败: 0x2`），
结果是**旧 exe 被删掉、新 exe 没生成**，看起来像「打包失败」。所以**先把要覆盖的 exe 挪走再打**（上面第一条命令）。
★ `web\` 是打进包的 → **改了网页就要重打包**，且**正在运行的旧实例不会自动变**，要让用户重开程序。
★ **例外（2026-10-15 加）：两张爬升大图走 `web_live\raise\` 磁盘覆盖层** —— `server.py: live_raise_target()`
  让 `/web/raise/…` 优先读 exe 同目录的 `web_live\raise\`，所以**只换大图不必重打包**（`refresh_deliverables.py`
  第 4 步自动同步）。覆盖范围**故意只限 `raise/`**：`web` 与 `web_nopass` 只差一个 `index.html`、`raise/` 完全一致，
  所以一份覆盖对四个变体都安全，不会把变体页换错。
★ 改 `web/index.html` 时**必须同步改 `_features/index_original.html`**（无过境预报变体页），
否则两套 exe 的功能会不一致；`_make_nopass.py` 的指纹守卫就是防这个漏改的。

## 五、已知边界（非 bug）

- 覆盖圆语义 = 「地面站点**至少能看见这颗星**」的几何范围，**按可调最低仰角 e 算**：
  `β = acos(Re/(Re+h)·cos e) − e`，可选 5/10/15/20/30°、**默认 10°**（0° 就是旧口径的几何地平线）。
  以千帆 1068.5 km 为例：0° = 3459 km / 10° = 2503 km / 30° = 1349 km。
  ★ 它**不是运营方服务区**：不含波束、指向、链路预算、遮挡等；低轨单星圈大且互相重叠（千帆 257 颗在 0° 下重叠约 18 倍）。
  ★ 与「过境预报」的最低高度角**共用同一个取值**（两处控件互相同步），改哪边都一样。
  ★ **2D 上画的是球面真圆的等经纬度投影，不是椭圆**（2026-10-07 再改）：覆盖区在球面上是球冠，
    只有星下点在**赤道**时东西 = 南北 = β；纬度越高东西越宽（β=22.5° 时 45°→32.7°、60°→49.9°），
    `|φ0| > 90° − β` 时球冠含极点、东西跨满 180°，看起来是一条**绕极横带**。
    实现 = `capColumns`（逐列解纬度上下界）+ `paintCap2D`（沿经度 1×/3× 复制防接缝缺块）。
    ★ 两个解**必须先各自归一化到 ±180° 再筛 [−90, 90]**，否则 φ0<0 时南半球极冠只画一半。
    2D 那个**观测点地平圈**（红色虚线）用的是同一个函数（半径按星网高度 1150 km 作参考）。
  ★ **轨迹 / 覆盖圆开关语义 = 「开关优先」**：关掉就一颗都不画（2D 与 3D 同规则）。旧版 2D 是
    `isSel || (S.coverOn && !S.selected)`，**选中了星就无视开关**、按钮形同虚设，已修。
- CelesTrak 对千帆批量部署星只给批次级 OBJECT_ID（无分颗字母），源头如此。
- 星网技术试验星（`HULIANWANG JISHU SHIYAN`，前身名 `GUOWANG TEST OBJECT`）**不在分组里、不显示** ——
  快路径组接口会把它们一起带出来，靠 `server.py: filter_group_rows()` 按名字关键字（`TEST` / `JISHU SHIYAN`）剔除。
  ★ **2026-10-07 源头把这 4 颗改名**，原来只按 `TEST` 过滤就失效、国网虚增到 217（合计 477）；已补齐关键字恢复 **213 / 473**（2026-10-15 随星网低轨27组入库，口径升为 **220 / 480**；2026-10-19 官方补发 `100975`/`100976` 根数，再升为 **222 / 482**）。
- 「过境预报」算的是**几何过境**（高度角 ≥ 阈值），**不考虑日照、不预报星等**；经纬度精度 ~0.1°≈11 km。详见 `说明.md` §六。
- 单星历史只有逐日积累（sat_hist.json 抽自两份大图数据），无逐点 TLE 历史。
- **`交付物\01\` 里的状态表 xlsx / csv 不在自动更新范围内**：那是 09-27 独立核查管线的产物
  （口径是当时编目的 186 颗），不跟查看器实时数据联动，要新的得单独重算。
